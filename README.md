# HTMLScalpel
a HTML editor
一款html文件可视化编辑应用。
AI生成html文件进行演示的方法开始流行，但html文件不能像ppt文件那样可视化进行修改，需要用户进入编辑模式并使用html语言进行修改。
为了方便对html不熟悉的用户进行可视化编辑，开发这款html手术刀应用，只需要将ai生成的html文件导入，即可在演示界面上直接进行修改。
使用方法：
·编辑模式：点文字直接改，选中文字调样式
点「插图」可像 PPT 一样在页面上放图，拖动移动、拖角缩放
点「文本框」可在空白处加一段可调字号的文字。 
·模块模式：点任意模块改背景色、复制、上下移、删除。
撤销最多 10 步，
